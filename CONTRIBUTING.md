# Contributing to TheCodeOfTruth

Thank you for your interest in contributing to this repository!

This repository is focused on **Data Structures & Algorithms using Java**, including LeetCode solutions and pattern-based DSA practice.

---

## Before You Start

Please search the repository before adding a problem so that solutions do not get duplicated. Keep each change focused on one topic or improvement.

## Adding a Solution

1. Choose the correct topic directory.
2. Use a filename containing the problem number and title, for example `0027_Remove_Element.java`.
3. Keep the platform-compatible class and method signature.
4. Document the approach and complexity in the file header.
5. Compile the changed Java file before opening a pull request.

For practice problems, place the solution in the most specific pattern directory under [`practice/`](practice/).

## Pull Requests

- Use a short, descriptive title.
- Explain the algorithm and its complexity.
- Include the problem link when applicable.
- Keep formatting and naming consistent with nearby solutions.
- Do not commit generated `.class` files or IDE metadata.

## Commit Messages

Prefer imperative, focused messages such as:

```text
Add two-pointer solution for Remove Element
Update array practice roadmap
```

## 📂 Repository Structure

The repository is divided into two major sections:

```text
DSA/
│
├── leetcode-java/

│
├── practice/
│   └── Pattern-based DSA practice
│
├── README.md
```

## Review Standard

Contributions are reviewed for correctness, clarity, appropriate complexity, and consistency with the surrounding topic. A solution does not need to be clever; it needs to be understandable and defensible.

Thanks for helping make **TheCodeOfTruth** a useful place to learn.
